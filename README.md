# 🍃 Workshop Spring Boot + MongoDB

API REST desenvolvida em Java com Spring Boot durante o curso do Nélio Alves, com o objetivo de praticar o desenvolvimento de aplicações web utilizando **MongoDB** como banco de dados NoSQL.

## 📚 Conceitos aplicados

* Spring Boot
* Spring Data MongoDB
* API REST
* Arquitetura em camadas
* Injeção de Dependência
* CRUD
* Modelagem de documentos
* Relacionamento entre documentos
* Tratamento de exceções
* Padrão DTO
* Repository Pattern
* HTTP e métodos REST

## ⚙️ Funcionalidades

* Gerenciamento de usuários
* Gerenciamento de posts
* Busca de usuário por ID
* Busca de posts
* Associação entre usuários e posts
* Criação e persistência de documentos no MongoDB
* Operações CRUD através de API REST
* Tratamento de recursos não encontrados

## 🗄️ Banco de Dados

O projeto utiliza **MongoDB**, um banco de dados NoSQL orientado a documentos.

As entidades principais trabalhadas no projeto são:

* `User`
* `Post`

Os dados são armazenados como documentos no MongoDB, utilizando o Spring Data MongoDB para realizar a comunicação entre a aplicação e o banco de dados.

## 🛠️ Tecnologias

* Java
* Spring Boot
* Spring Data MongoDB
* MongoDB
* Maven
* Git
* GitHub

## 🎯 Objetivo

Este projeto foi desenvolvido para consolidar conhecimentos em desenvolvimento de APIs REST com Spring Boot e MongoDB, aplicando conceitos de arquitetura em camadas, injeção de dependência, persistência de dados NoSQL, DTOs, tratamento de exceções e relacionamento entre documentos.

O projeto faz parte dos estudos de desenvolvimento backend em Java, servindo como prática para a construção de aplicações web utilizando tecnologias presentes no mercado.
